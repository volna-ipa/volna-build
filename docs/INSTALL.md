# Установка Volna на iPhone

Короткая инструкция без технических деталей. Все команды выполняются в PowerShell
в папке проекта `C:\Users\ALEX\Documents\Проект по умолчанию\Volna`.

## Что уже готово

- Код приложения и Xcode-проект.
- Приватный репозиторий GitHub: `volna-ipa/volna`.
- Workflow **Build unsigned IPA**, который собирает `.ipa` на macOS-сервере GitHub.

## Шаг 1. Скачать готовый IPA

```powershell
powershell -ExecutionPolicy Bypass -File tools/fetch-ipa.ps1
```

Скрипт найдёт последнюю успешную сборку, скачает её и положит файл сюда:

```
build\Volna-unsigned.ipa
```

Если сборки ещё нет:

```powershell
gh workflow run build-ipa.yml --repo volna-ipa/volna
gh run watch --repo volna-ipa/volna
```

## Шаг 2. Подключить iPhone

1. Подключите iPhone кабелем.
2. Разблокируйте телефон.
3. На телефоне нажмите **Доверять** (Trust).
4. На компьютере должен быть установлен **Apple Mobile Device Support**
   (ставится вместе с iTunes или Apple Devices).

## Шаг 3. Установить приложение

```powershell
powershell -ExecutionPolicy Bypass -File tools/install-to-iphone.ps1
```

Скрипт проверит драйверы, найдёт Sideloadly и откроет его с уже выбранным IPA.

Дальше в окне Sideloadly:

1. Проверьте, что в поле **Device** выбран ваш iPhone.
2. Перетащите `build\Volna-unsigned.ipa` в окно Sideloadly, если файл не подставился сам.
3. Введите **Apple ID** и пароль (это делает Sideloadly, приложение Volna их не видит).
4. Нажмите **Start**.
5. Дождитесь надписи **Done**.

## Шаг 4. Доверить приложению на iPhone

1. Настройки → **Основные** → **VPN и управление устройством**.
2. В разделе «Приложения разработчика» выберите ваш Apple ID.
3. Нажмите **Доверять**.
4. Запустите **Volna** с домашнего экрана.

При первом запуске выберите любимые жанры и артистов — лента соберётся сама.

## Что важно знать про бесплатный Apple ID

- Приложение работает **7 дней**, потом нужно снова нажать **Start** в Sideloadly
  (файл IPA остаётся тем же).
- Одновременно можно держать не больше **3** приложений, установленных таким способом.
- Если Sideloadly просит «app-specific password» — это пароль, созданный на
  [account.apple.com](https://account.apple.com) в разделе «Безопасность»,
  а не обычный пароль от Apple ID.

## Частые вопросы

| Симптом | Что делать |
|---|---|
| `IPA не найден` | Сначала выполните `tools/fetch-ipa.ps1`. |
| `Успешных сборок пока нет` | Сборка ещё идёт или упала. Откройте Actions на GitHub и посмотрите лог. |
| `Sideloadly не найден` | `winget install iOSGods.Sideloadly` или скачайте с [sideloadly.io](https://sideloadly.io/). |
| iPhone не виден | Разблокируйте, нажмите «Доверять», переподключите кабель, проверьте Apple Mobile Device Service. |
| `Unable to install` | Обновите Sideloadly, проверьте, что iPhone разблокирован, и попробуйте другой USB-порт. |
| Приложение закрылось через 7 дней | Снова откройте Sideloadly и нажмите Start. |

## Режимы работы приложения

| Режим | Что нужно | Что играет |
|---|---|---|
| **Бесплатный (сейчас)** | Ничего | Официальные 30-секундные превью Deezer |
| **SoundCloud** | Client ID + Client Secret (Artist Pro) | Полные треки |

В бесплатном режиме приложение полностью работает: лента, поиск, лайки, плейлисты,
история, плеер. Отличается только длительность трека — 30 секунд.
